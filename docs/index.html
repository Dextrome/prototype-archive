A NOTE FROM THE WORKSHOP

Ideas deserve
a little room to play.

This is a collection of unreleased 7ants projects: some have working game loops, some are experiments in feel, and some are short films built to ask, “Would you want to play this?”

Every film tells you what you’re seeing. Gameplay trailers use a running build, sometimes driven by scripted inputs or bots. Staged concept films demonstrate an idea.

These are works in progress, not release promises. Features and visual direction may change.
