# 7ants — The Prototype Archive

A buildless, responsive gallery of 18 unreleased games and concept studies, with gameplay loops, 51 screenshots, and 18 films. Slot Theory, DexUO, Bloodline, Card Scalper, AnthroWorld, Orpob and BlorpBrawl are excluded.

## Open it

The site is published with GitHub Pages from `main` → `/docs`.

To preview locally, open `docs/index.html` directly, or serve `docs` with any static HTTP server. There are no dependencies, analytics, accounts, third-party media embeds or build step. All media is local to the site.

## Update it

- Project copy, loop steps, captions and film labels: `docs/catalog.js`.
- Layout and responsive styling: `docs/style.css`.
- Filtering, search, project dialogs, image viewer and share links: `docs/app.js`.
- Media: `docs/assets/<project-id>/`.
- Credits and staging disclosures: `docs/credits.html`.

Keep the distinction between real gameplay, staged concepts and screenshot reels when replacing media. The five original factory concept films preserve their authored sequence. New edits follow the same immediate hook → interaction → consequence → payoff structure.

The gallery contains rendered media, not the game source projects or models. Refer to the media credits before reusing assets.

Gurk has an extended 1:56 feature trailer with an original score and game foley. Its real-renderer footage uses staged setups; the media notes describe the capture method.

ShpinkyDinky’s 27-second engineered-kills showcase uses four scripted scenarios and native game audio. Each one demonstrates a verified interaction and outcome rather than random bot movement.

Dungeon Janitor now features the original 59-second DungeonJanitorV5 factory film, including trap reset, survivor pursuit, trapping and disposal. The film is preserved intact and labeled as a staged concept showcase.


Goblin Ballistics has a new 20-second gameplay edit with independent, ball-aware flipper taps. Four left taps and two right taps replace constant simultaneous flipping; native physics and scoring are unchanged. The trailer uses two excerpts from one run and is silent.

Sobriety Kills now has a 46-second combinations showcase covering all seven slice substances, four contrasting combat setups, a native merge, and cardiac and respiratory overdose endings. Later-wave stashes are staged; game rules and death outcomes remain native. Overdose sequences are slowed for readability.

Squabblobs has a faster 44-second trailer: 27 seconds of nine weapon/power demonstrations, then 16 seconds of four-player free-for-all across three stages. The finale uses unchanged native bots and normal spawn points, with selected loadouts and closer camera framing. Gameplay runs at normal speed; draft picks are accelerated and forward cuts remove downtime. Native procedural sound effects are retained.

Murderbox has a 61-second modules and synergies showcase covering all three weapons and 14 module types. Native adjacency bonuses, a real hover tooltip, repeat shots, repairs, shields, overheating, vent blasts and cooling are explained on screen. Builds and enemy queues are staged in an isolated copy; the game code is unchanged and native procedural sound effects are retained.

Mazacre TD has a 1:17 run-progression trailer: nine waves grow a 37-cell route into a 190-cell maze with checkpoint-group separation, a shared choke, Piledriver specialization, damage/speed upgrades, supply and all four research categories. Native bot maze plans and curated purchases are replayed through real UI commands with earned minerals. Combat runs at the game’s visible 4× speed; brief planning shots are held for explanation. Native sound effects are retained.
