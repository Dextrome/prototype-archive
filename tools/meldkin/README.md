# Meldkin trailer capture

Run from the repository root on Windows with Python (Pillow, numpy, opencv-python), FFmpeg, .NET 8 and Godot 4.6.1 Mono. Source stays at E:/Meldkin; staging is under work/meldkin-trailer. No desktop capture is used. Capture windows render offscreen.

1. `python tools/meldkin/prepare.py`
2. `dotnet build work/meldkin-trailer/project/Meldkin.sln`
3. `python tools/meldkin/capture.py import`
4. `python tools/meldkin/capture.py 0` (repeat for 1, 2 and 3)
5. `python tools/meldkin/edit.py`

The director adds legal placements and buys native path rungs. It jumps to authored waves 22, 31 and 39 with staged funds and lives. The shop uses --growth_save and --growth_grant_xp to isolate its three purchases. Existing authored code is copied unchanged; generated map bakes may refresh. The edit is 67 seconds, normal gameplay speed, with forward cuts, editorial captions and native procedural audio. Outputs go to outputs/; generated source/captures stay under work/ and are not part of the website.
